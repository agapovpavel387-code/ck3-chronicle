# Изменения / Changelog

## 0.1.1-alpha — 2026-11-06

Импорт своего сохранения наконец работает у всех, а не только на машине разработчика. / Importing your own save now works for everyone, not just on the developer's machine.

### Импорт / Import

- Экстрактор запускается из рабочей папки: Windows не даёт писать в `Documents`, из-за чего любой импорт падал с «Отказано в доступе» на шаге дампа. `import_save.py` теперь копирует `exe`, `tokens_1.tok` и `templates/` в рабочую папку и работает оттуда.
- Запасная попытка больше не передаёт относительный путь в `-o`.

### Публикация / Publishing

- Готовая сборка экстрактора с патчем 1.20 — в Releases: `ck3_history_extractor-2.4.7-ck3-1.20-win64.zip` (exe, `templates/`, лицензия TCA). Собирать из исходников больше не нужно.
- README, заметки к выпуску и памятка по публикации ведут в Releases.
- `vendor/` и `*.exe` не попадают в git.

## 0.1.0-alpha — 2026-11-05

Первая альфа для Crusader Kings III 1.20.x. / First alpha for Crusader Kings III 1.20.x.

### Приложение / App

- Пять экранов: Род, Мир, Хроника, Свод, Досье; плюс «Своё сохранение» и «Данные».
- **Род** — конспект по слоям: строка на человека, отступ на поколение, сворачивание, поиск с раскрытием пути. Полотно с панорамой — второй режим.
- **Мир** — две линзы: радиус знания и политическая, у политической два слоя — по домам всех держав и земли рода.
- **Хроника** — главы по эпохам, три слоя внутри года (в роду / при дворе / издали), нити войн и распрь, честный счёт пропущенного.
- **Свод** — поколения, ветви, кто чем владеет, авантюристы.
- **Досье** — пакет фактов для рассказчика: линии рода, дома, державы, верования.
- Карточка человека: родство с вами, владения, культура, вера.
- Интерфейс полностью двуязычный: навигация, кнопки, легенды, карточка человека, форма хроники, свод, импорт. Переключатель RU/EN, выбор запоминается; по умолчанию — язык браузера.
- Текст летописи, досье и родства идёт на языке сейва: это цитаты из источника.

### Инструменты / Tools

- `import_save.py` — импорт сохранения в один запуск: дамп → мир → карта. Из панели или из командной строки.
- `serve.js` — локальный сервер с API: список сохранений, статус окружения, импорт с прогрессом, отмена, установка зависимостей.
- `build_world.py` — сборка мира: державы, люди, события, линии рода, карты, таблицы.
- `doctor.py` — диагностика дампа: дома, династии, персонажи, игрок.
- `knowledge_pilot.py` — кэш карты из файлов игры.
- Проверки: `npm test` — 37 + 15 + 14 + 12.

### Рефакторинг / Refactor

- `app/app.js` (2679 строк) разделён на 11 модулей в `app/js/`: ядро, род, полотно, управление родом, карта, хроника, свод, досье, оболочка, импорт, точка входа. Классические скрипты без сборки — двойной щелчок по `index.html` по-прежнему работает.
- Убраны дубли определений (`lineage`, `lineById`, `lineColor`) и мёртвый код (`currentLine`, `branchOrder`, `passed`).
- Порядок скриптов берётся из `index.html` и для страницы, и для проверок (`tools/app_scripts.js`) — один источник правды.

### Экстрактор / Extractor

- Патч под 1.20: неизвестные токены, битые секции, `dead_unprunable` массивом, `faiths` как определения вер, культура графств сохраняется.

### Для разработки / Development

- Проверки идут в CI (`.github/workflows/tests.yml`): `npm ci` + `npm test` на Node 20 и `python -m compileall` для `tools/`.
- `package-lock.json` зафиксирован — сборка на чистой машине воспроизводима.
- В README добавлены скриншоты пяти экранов (`docs/screenshots/`).

### Известные ограничения / Known limitations

- Вера в сейвах 1.20 не привязана к людям и графствам — приложение говорит об этом прямо.
- Причины событий сейв не хранит: хроника фиксирует «что», не «почему».
- Имена государей за третьим кольцом неизвестны — это кольцо молвы.
