## Блокеры

### P1. Пуш в GitHub не сделан

Двадцать один коммит и одиннадцать тегов лежат только локально: на GitHub есть
только `v0.1.0-alpha` и `0.1.1-alpha`, а `main` там — `557e34d`, без истории 0.5–0.6.
`origin` подключён, локальный `main` ушёл вперёд.

- **Почему не сделано:** решение пользователя — «только коммиты, без пуша».
- **Что нужно:** `git push origin main` и `git push origin --tags`. Затем по
  `PUBLISHING.md` — описание, темы и Release с архивом текущей версии.
- **Проверка:** `git rev-list --count origin/main..HEAD` возвращает `0`;
  `git ls-remote --tags origin` показывает все теги; на GitHub виден Release.

## Крупное

### P2. Тайлы для зума выше 4×

Сейчас карта титулов — один PNG 4594×2304. При зуме больше 4× картинка мягкая:
не хватает пикселей, а не вёрстки.

- **Почему не сделано:** полный рендер 9216×4608 требует ~400–500 МБ памяти
  за один проход (canvas + четыре массива `int32` + слой провинций). Риск уронить
  сборку в конце захода.
- **Как делать:**
  1. `titles_render.py`: рендер блоками по 512 строк с записью плиток сразу на диск —
     память остаётся постоянной.
  2. Плитки 1024×1024: 9×5 = 45 файлов карты и 45 индексных, в `app/_data/tiles/`.
  3. `map.js`: при `zoom > 2.5` показывать сетку `<img>` с абсолютным
     позиционированием; грузить только видимые плитки; индексы — тоже плитками.
- **Проверка:** `check_lens.js` — при зуме 3× в DOM появляются плитки, подсказка
  и клик работают как раньше; память сборки не растёт выше 300 МБ.
- **Оценка:** 2–3 шага.

### P2. Одинаковые имена титулов в списке и в летописи

На сейве 917 года четыре пары держав с одинаковым именем:

| Имя | Что это |
|---|---|
| Ляоси | графство и герцогство |
| Тханбьюзаят | **два графства** — настоящий дубль |
| Хандуманс | герцогство и графство |
| Ниас | герцогство и графство |

В событиях ещё 971 повторяющееся имя титула из 1877 уникальных: «Ахен» может быть
графством, а «Ахен» — герцогством.

- **Почему важно:** рассказчик не понимает, о каком Ахене речь, — а ключи у них разные.
- **Как делать:** показывать тир рядом с именем в списке держав, в панели карты и
  в записях хроники: «Ахен (графство)». Данные уже есть — `tier` в событии и державе.
- **Проверка:** новая проверка в `check_chronicle.js` — ни одного имени без тира
  там, где имя встречается дважды.
- **Оценка:** 1 шаг.

### P2. Тёзки персонажей не различаются

В чужих мирах встречаются два разных человека с одним именем — например, Ума,
дочь Кртаджнавиры, и Ума, родившаяся позже; Раджагуха-жена и Раджагуха-сын.

- **Почему не сделано:** нужна выгрузка, где это видно (957 год, дом Ибиси); в мире 917
  тёзок среди 29 человек нет.
- **Как делать:** в записи о человеке, если имя встречается среди родичей больше
  одного раза, добавлять год рождения: «Ума (род. 919)». Ключ — `id`, он уже разный.
- **Проверка:** тест на синтетическом мире с двумя тёзками — строки различаются.
- **Оценка:** 1 шаг после появления подходящего сейва.

## Среднее

### P2. Нет проверок для `knowledge_pilot.py`

Инструмент строит кэш карты (`map`, `adjacency`, `centroids`) из `map_data` игры.
Без игры не запускается, поэтому проверки нет.

- **Как делать:** `--selftest` на синтетической `adjacencies.csv` и крошечном
  `provinces.png` 4×4, созданных во временной папке.
- **Проверка:** `npm test` включает `python tools/knowledge_pilot.py --selftest`.

### P3. Три двойные записи событий

**Закрыто в 0.6.5.** `build_world.py` сводит дубли по ключу (вид, дата, участники, тип, титул);
`check_chronicle.js` проверяет, что их не осталось. Ниже — исходная запись.

Среди событий мира три пары полностью совпадают (вид, дата, участники, тип):

- `prison` 0885-10-04, `prison` 0893-12-31 — «в заключении»;
- `friendship` 0898-09-24 — «стали друзьями».

- **Как делать:** дедупликация в `build_world.py` по `(kind, date, who, who2, type)`
  перед сортировкой событий.
- **Проверка:** `check_chronicle.js` — ни одной полной пары.

### P3. Девять держав без культуры, три без расстояния

В мире 917: у 9 держав нет `culture`, у 3 — `distance`. Вероятно, данные игры
(безземельные дворы, кочевья), но в досье это даёт пустые скобки.

- **Как делать:** проверить на дампе, действительно ли пусто; если да — не выводить
  пустое поле, а писать «культура не записана».
- **Проверка:** в `check_chronicle.js` — нет строк с `()` и `— ·`.

### P3. `why: ""` вместо `null`

**Закрыто в 0.6.5.** Мир пишет `null` там, где причины нет; проверка «пустая причина — это null»
в `check_chronicle.js`.

У событий без причины поле `why` — пустая строка, а не `null`. Проверки опираются
на truthy, так что не ломает, но данные неряшливы.

- **Как делать:** в `build_world.py` писать `reason_text(...) or None`.
- **Проверка:** `check_chronicle.js` — `typeof e.why === 'object'` для пустых.

### P3. Два титула без имени в дампе

`c_nf_viet_ly_two` и `d_poor_clares` — у них нет названия в игре. На карте вместо
пустоты показывается ключ.

- **Как делать:** ничего, если ключ читается. Либо писать «безымянное графство».
- **Проверка:** глазами на карте титулов в том районе.

### P3. Счётчики «издали» не сходятся между выгрузками

В отчётах по 917 и 920 годам числа «войн», «смертей», «смен власти» за один и тот же
год разные — 77 против 39 смен за 867-й.

- **Почему:** это разные срезы одной партии; 920-й снят позже, и события за прошлые
  годы могли дополниться.
- **Как делать:** если понадобится — сверять два среза на одном дампе и смотреть,
  не теряет ли счётчик войны до 870 года (фильтр `now_year - 60`).
- **Проверка:** собрать мир из двух дампов и сравнить `byYear`.

### P3. `world.js` грузится целиком — 10 МБ

Локально это 239 мс, но при первом открытии через сеть будет заметно.

- **Как делать:** минимум — gzip в `serve.js` (уже отдаёт статику, сжатия нет).
  Сильнее — разбить на «люди», «события», «карты» и грузить по требованию.
- **Проверка:** `curl -H 'Accept-Encoding: gzip'` возвращает `Content-Encoding: gzip`;
  размер ответа падает втрое.

### P3. Мобильная вёрстка не проверялась на устройстве

В CSS есть брейкпоинты 1040 и 820 px, но на реальном телефоне приложение не открывали.

- **Как делать:** открыть через `start.cmd` с телефона в той же сети (сервер слушает
  только `127.0.0.1` — понадобится `--host`), пройти по шести экранам.
- **Проверка:** карта не уезжает, дерево прокручивается, кнопки не меньше 44 px.
