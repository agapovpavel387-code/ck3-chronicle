# Что отдаёт экстрактор и что приходится брать из сейва

Короткая памятка: где в конвейере теряются данные и чем это проверяется.
Числа сняты на сейве 917 года (Шу, 1.20.0.2) — `tools/check_dump.py`.

## Два источника, а не один

```
сейв .ck3 ──┬── ck3_history_extractor.exe ──► gamestate.json ─┐
            │     (сторонний проект, MIT)                      ├──► build_world.py ──► world.json
            └── tools/save_reader.py ───────► save-extra.json ─┘
                  (войны и история титулов)
```

**Дамп экстрактора** — 14 секций: `characters`, `titles`, `faiths`, `cultures`,
`dynasties`, `houses`, `memories`, `artifacts`, `traits_lookup`, `contract_transform`,
`character_transform`, `players`, `current_date`, `offset_date`.

Чего в нём нет:

| Чего нет | Где лежит | Кто добавляет |
|---|---|---|
| `wars`, `casus_belli` | `wars.active_wars` в текстовом `gamestate` | `tools/save_reader.py` |
| Часть истории титулов | `landed_titles.<id>.history` — карта и блоки с `holder`/`type` | `tools/save_reader.py` |
| Причина смерти используется | `dead_data.reason` — **есть** в дампе полем `reason` | `build_world.py` (`cause`) |

## Числа на сейве 917 года

| Показатель | Дамп экстрактора | После `save_reader.py` |
|---|---|---|
| Титулов | 19 776 | — |
| Титулов с историей | 7 238 (41 065 записей) | 6 899 титулов в сейве дают 39 084 записи, из них 20 054 — после 0867 |
| Войн с поводом | 0 | **112** (75 с целью-титулом, 28 разных поводов) |
| Переходов власти в мире | 1 224 (816 после 0867) | **1 177** (812 после 0867), дубли сведены |
| Смертей с причиной | 0 (не читалась) | **2 722 из 2 811** |

История в дампе и в сейве не совпадает: дамп укорачивает часть титулов,
сейв даёт пропущенные записи — **4 949 из 6 899** титулов получают строки, которых в дампе нет
(полностью совпадают только 1 940). Поэтому слияние идёт по `key` титула:
id в дампе и в сейве разные (`c_parsberg` — 863 в дампе, 951 в сейве).

## Границы

* В сейве только `active_wars`: завершённых войн игра не хранит. Причина войн,
  которые шли и кончились до сохранения, из одного файла не восстанавливается —
  её можно накопить, если сохранять сейвы по ходу партии.
* Бинарные сейвы (ironman) так не читаются: в них нет текстового `gamestate`.
  Импорт работает как раньше — без войн и без дополненной истории.
* Повод — ключ (`county_conquest_cb`). Словарь человеческих названий —
  `CB_RU` в `build_world.py`; незнакомый ключ выводится как «повод «…»», без выдумок.
* Причина смерти берётся из игры как есть: строки вида «во сне»,
  «от старости», иногда с мусором вида `[Select_CString(...)]` — это данные игры.

## Поводы войн

Имена берутся из локализации игры, а не пишутся руками: ключ повода совпадает
с ключом локализации (`county_conquest_cb: "Завоевание графства"`).
Собирает `tools/cb_names.py` → `_cache/cb-names.json`:

* **112 из 118** поводов игры получают имя (русское и английское);
* остальные 6 — служебные/непереведённые, для них работает словарь `CB_RU`;
* `$ПЕРЕМЕННЫЕ$` и разметка (`[Concept(…)|E]`, `#TOOLTIP:…#L`, `#V…#!`) раскрываются;
* где игра отдаёт обрубок концепта («Minor», «Священная») — свой вариант в `OVERRIDES`.

Примеры из словаря: `claim_cb` — «Претензия» (не «притязание»), `duchy_conquest_cb` —
«Покорение герцогства» (а `ducal_conquest_cb` — «Завоевание герцогства»),
`chinese_consolidation_cb` — «Война за объединение Китая», `make_tributary_cb` —
«Обложить данью», `minor_religious_war` — «Малая священная война».

### Семейства поводов

От семейства зависит фраза в летописи (`cb_family` в `build_world.py`,
`CAUSE_RU` в `chronicle.js`):

| Семейство | Как звучит | Примеры ключей |
|---|---|---|
| `holy` | за веру | `minor_religious_war`, `major_religious_war`, `religious_war` |
| `tribute` | за дань | `make_tributary_cb` |
| `mandate` | за верховенство | `chinese_consolidation_cb`, `mandala_raze_capital_structure_cb` |
| `faction` | за вольности | `liberty_faction_war`, `claimant_faction_war`, `populist_war` |
| `conquest` | за землю | `county_conquest_cb`, `nomadic_conquest_cb`, `tribal_subjugation_cb` |
| `claim` | за титул | `claim_cb`, `de_jure_cb_nomadic`, `county_struggle_cb` |

На сейве 917 года: 42 завоевания, 33 фракции, 20 притязаний, 7 священных,
3 дани, 3 за верховенство, 4 прочих. Роли: напали / на нас напали / третья
сторона — от этого тоже зависит строка.

## Войны из воспоминаний

Идущие войны — только вершина: в сейве 917 года их 112, а воспоминаний о войнах — **7 343**.
У каждого есть дата, противник и переменная `war_cb` — категория повода:

| Категория | Записей | Как звучит |
|---|---|---|
| `war_memory_cb_conquest` | 2 201 | завоевание |
| `war_memory_cb_claim` | 1 208 | притязание |
| `war_memory_cb_fallback` | 954 | война (игра не уточнила) |
| `war_memory_cb_tyranny` | 835 | война против тирании |
| `war_memory_cb_peasant` / `_populist` | 563 / 296 | мятеж |
| `war_memory_cb_subjugation` | 316 | покорение |
| **`war_memory_cb_holy_war`** | **301** | священная война |
| `war_memory_cb_liberty` / `_independence` | 174 / 68 | за вольности |
| `war_memory_cb_de_jure` | 96 | возврат по праву |

Роль берётся из типа воспоминания: «наступательная война» — мы напали,
«оборонительная» — на нас. Имена участников в дампе уже есть готовыми —
их нельзя терять при переходе на числовые id.

На сейве 917 года после разбора: **4 155** событий с поводом из памяти и 112 из `active_wars`.
У нашего дома — **21** событие (10 объявлений и 11 побед, 892–917 годы):
4 мятежа, 1 вторжение, 16 с общей категорией «война» — игру устроители не уточнили, и мы не выдумываем.

## Как проверять

```powershell
# 1. Разбор сейва на синтетическом примере — без игры и без сейва
python -X utf8 tools\save_reader.py --selftest

# 2. Имена поводов: сколько из них нашлось в локализации
python -X utf8 tools\cb_names.py --game "...\game" --keys-from _cache\save-extra.json --check

# 2. Что нашлось в настоящем сейве
python -X utf8 tools\save_reader.py --save "...\last_save.ck3" --check

# 3. Дамп экстрактора против эталона
python -X utf8 tools\check_dump.py --dump "...\gamestate.json" --compare docs\dump-baseline.json

# 4. Сборка мира с дополнением и без — числа должны отличаться только войнами и историей
python -X utf8 tools\build_world.py --dump ... --extra _cache\save-extra.json -o world.json
```

`docs/dump-baseline.json` — снимок дампа 917 года. Если после пересборки экстрактора
титулов или персонажей стало меньше, `check_dump.py` падает: это признак регресса,
а не «хроника стала короче».
