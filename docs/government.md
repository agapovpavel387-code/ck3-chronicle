# Двор: форма правления, наследование, министры

Экстрактор CK3-history-extractor этого не отдаёт вовсе: в дампе `government`,
`succession`, `council`, `heir` и `ministry` — ноль вхождений. Всё берётся из
самого сейва, тем же путём, что и вера.

## Что где лежит

| Что | Где в сейве | Как читаем |
| --- | --- | --- |
| Форма правления | `government=<ключ>` у персонажа-правителя | `tools/save_reader.py` |
| Очередь наследования | `succession={ id, id, … }` | там же |
| Прямые наследники | `heir={ id, … }` | там же |
| Совет | `council={ id, … }` | там же |
| Мандатная заслуга | `merit={ currency … }` | там же |
| Название формы | `game_concept_<ключ>` или `<ключ>` в локализации | `tools/government_names.py` |
| Министерства | титулы `e_minister_*` в дампе | `tools/build_world.py` |

Названия форм правления ищутся по трём ключам подряд: `game_concept_<ключ>`,
`<ключ>`, `<ключ>_realm`. Для мандатного правления игра даёт
«Мандатное правление» через понятие, а в `government_l_russian.yml` этого ключа
нет — поэтому порядок именно такой.

## Министерства — это титулы

Девять титулов имперского тира, каждый со своим держателем:

```
e_minister_chancellor      Канцелярия
e_minister_grand_marshal   Великий маршал
e_minister_censor          Цензор
e_minister_of_war          Министерство войны
e_minister_of_justice      Министерство наказаний
e_minister_of_personnel    Министерство чинов
e_minister_of_revenue      Министерство доходов
e_minister_of_rites        Министерство обрядов
e_minister_of_works        Министерство общественных работ
```

Министр — тот, кто держит титул на дату сейва. Нет держателя — «место пусто»,
никаких подстановок.

## Что видно в приложении

- **Досье**, раздел «Державы в поле зрения»: `правление: …`, вера, культура,
  затем строка престолонаследия и список министерств с держателями.
- **Карта**, панель державы: правление и заслуга, вера, очередь наследования.
- **Хроника**: смена власти с причиной «перешёл по назначению» уже разбирается
  (`titles.py`), таких событий в демо-мире сотни.

## Ограничения

- Роли в совете не читаются: `council={ id, … }` даёт состав, а `councillor=`
  в сейве — это ссылка внутри задач, а не должность. Поэтому совет показываем
  списком имён без должностей.
- Устройство министерств (полномочия, законы, задачи) в сейве не найдено —
  показываем только титул и держателя.
- Держава без `government` в сейве остаётся без строки правления.
