# Вера: откуда она берётся

Экстрактор CK3-history-extractor веру не отдаёт: в его дампе у людей и графств
стоит `faith: null`, а секция `faiths` содержит одни номера без названий.
Поэтому вера читается не из дампа, а из самого сейва — своим кодом, без правок
и форков чужого проекта.

## Цепочка

```
человек / графство   rite = 54
        ↓
реестр `rites` сейва  54 → rite_type = vaishnavism, faith = 43
        ↓
common\religion\rite_types   vaishnavism → faith = hindu_faith
        ↓
localization\russian\rites_l_russian.yml   vaishnavism → «Вайшнавизм»
```

Ни одного шага «по догадке»: если обряда нет, вера остаётся пустой, и интерфейс
молчит, а не подставляет культуру или соседа.

## Кто что делает

| Файл | Роль |
| --- | --- |
| `tools/faith_names.py` | обряд → названия (RU/EN) и вера, из файлов игры; пишет `_cache/rites.json` |
| `tools/save_reader.py` | из сейва: реестр `rites`, `rite` у людей и графств — в `save-extra.json` |
| `tools/build_world.py` | наполняет `people[].faith`, `realms[].faith` / `faithShare` / `faiths`, `titles-map.json → faiths` |

## Что получается на демо-мире

Точные числа — в [facts.md](facts.md): сколько людей и держав получили веру и
сколько разных вер в мире. Замеры на живом сейве: обряды есть у всех персонажей
и у большей части графств.

Держава без веры — та, у которой ни одно графство не имеет обряда: так бывает у
кочевников и у земель без округов. Графство без веры — то, которого нет в
`county_manager` сейва.

## Ограничения

- **Названия только RU и EN.** Для остальных языков показывается ключ обряда
  (`roman_rite`) — это честнее выдумки.
- **Часть обрядов создана игрой по ходу партии** (динамические обряды): их нет в
  файлах игры, поэтому названия у них нет, и в интерфейсе стоит ключ.
- **Вера — на дату сейва.** Принятая позже вера в старом сейве не появится: мир
  собирается из одного сейва, а не из истории.

## Проверка

```powershell
$env:CK3_GAME = "<папка game игры Crusader Kings III>"
python tools/faith_names.py --check          # справочник сходится с игрой
python tools/check_titles.py --world app/_data/world.js   # вера в мире согласована
```

`tools/check_titles.py` проверяет три вещи: у людей с верой есть название, доля
веры державы лежит в (0, 1], и веру получает заметная часть держав.
